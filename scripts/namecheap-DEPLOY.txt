FIZAM — Namecheap deploy checklist (copy-paste)
=================================================

FULL GUIDE: docs/08-DEPLOY-NAMECHEAP.md in the GitHub repo.

BUILD (GitHub Actions)
----------------------
  Actions → "Namecheap standalone ZIP" → Run workflow
  Download artifact: fizam-namecheap-standalone (~60 MB)
  Rebuild if you change NEXT_PUBLIC_* (baked in at build time).

UPLOAD
------
  Extract into app root so server.js is at:
    /home/<user>/fizam.ng/server.js

  KEEP data/fizam.db on redeploy — do not delete data/

AFTER EXTRACT (SSH)
-------------------
  cd ~/fizam.ng
  bash scripts/namecheap-server-setup.sh
  # Or manually: see docs/08-DEPLOY-NAMECHEAP.md section "Post-extract"

  mv next-dist .next   (if not done by setup script)
  cPanel → RESTART Node app

DATABASE (pick one)
-------------------
  A) RECOMMENDED ongoing: keep data/fizam.db; back up before each deploy.
  B) First deploy / empty DB: upload dev data/fizam.db from your PC, OR
     after a build with prodMigrations, empty DB + Production restart runs migrations.

cPanel NODE APP
---------------
  Node 24.x (e.g. 24.15.0) | Mode: Production | Startup: server.js
  NODE_OPTIONS=--disable-wasm-trap-handler --require /home/<user>/fizam.ng/preload-sharp.cjs
  LD_LIBRARY_PATH=/home/<user>/nodevenv/fizam.ng/24/lib/node_modules/@img/sharp-libvips-linux-x64/lib
  Env: PAYLOAD_SECRET, NEXT_PUBLIC_SITE_URL=https://fizam.ng,
       PAYSTACK_SECRET_KEY, DATABASE_URI=file:./data/fizam.db, SMTP_*

VERIFY
------
  curl -sI https://fizam.ng/ | head -3        → HTTP/2 200
  curl -sI https://fizam.ng/admin | head -3   → HTTP/2 200
  tail -20 stderr.log                         → empty or no new errors

SHARP ON NAMECHEAP (required every venv refresh)
----------------------------------------------
  Use sharp@0.33.5 — NOT 0.34.x (CPU v2 error), NOT wasm (OOM).
  See namecheap-server-setup.sh
